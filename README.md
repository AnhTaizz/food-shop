
# food-shop

Website đặt mua đồ ăn trực tuyến được phát triển bằng Spring Boot theo mô hình MVC, sử dụng Thymeleaf cho giao diện và MySQL cho lưu trữ dữ liệu, hỗ trợ các chức năng đặt món và quản lý đơn hàng cơ bản.
